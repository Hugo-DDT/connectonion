# The heading that gave the section away

Sharing a person page at 只看公开 was supposed to be the view you could leave on a screen. The marked sentences were already gone. What stayed was the heading, sitting on an empty list, in the same place the section had been. Anyone looking over a shoulder could read the name of a section that now had nothing under it, which is enough to know the section had been there.

The obvious patch was a line under that heading: something private lives here. We wrote it down and then threw it away. The line would have said the same thing the empty heading already said. The footer already counts how many passages were taken out, and that count is for the person who owns the page.

So the heading goes with the list. A section that still has a public line keeps its name and that line; the private line in it stays out, the way it already did. On a fixture page the private-only section left a heading and a blank list before the change, and neither one after. The mixed section still read its public sentence, and the footer still said how many passages were hidden.
